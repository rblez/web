# rblez terminal

An interactive terminal-style portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

### Interactive Terminal
- Fully functional command-line interface
- Command history with arrow key navigation
- Tab completion for available commands
- Real-time typing animations
- Mobile-responsive design with touch support

### Available Commands
- `help` - Show all available commands
- `whoami` - Display personal information
- `about` - About me and my background
- `skills` - Tech stack and technologies
- `contact` - Find me online with links
- `open` - Quick access to projects (tiendly, memlink, github, x)
- `pwd` - Show current directory
- `projects` - List active projects with descriptions
- `now` - Current time and work status
- `clear` - Clear terminal screen

### Easter Eggs
- `sudo` - Permission denied messages
- `hack` - Animated hack sequence
- `matrix` - Matrix-style binary rain effect

### Visual Features
- Typing animation for welcome message
- Dynamic prompt colors (green for `rblez@Ray >`, white for input)
- Fade-in animations for output lines
- Responsive design for desktop, tablet, and mobile
- Custom favicon set for all platforms

### Technical Features
- Paste support (Ctrl+V) with clipboard API
- Mobile keyboard optimization
- Touch-friendly interface
- SEO optimized with meta tags
- Social media ready (Open Graph, Twitter Cards)

## Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Grid, Flexbox, CSS Animations
- **Icons**: Custom favicon set (multiple sizes)
- **SEO**: Complete meta tags, robots.txt, sitemap.xml

## Getting Started

Simply open `rblez.html` in your web browser. No installation required!

### Local Development

```bash
# Clone the repository
git clone https://github.com/rblez/web.git
cd web

# Open in your browser
open rblez.html
# or
python -m http.server 8000
# then visit http://localhost:8000
```

### Deployment

#### Vercel (Recommended)
Use the deployment script for automated deployment to Vercel:

```bash
# Deploy to Vercel
npm run deploy
```

#### Manual Deployment
```bash
# Install Vercel CLI (if not installed)
npm i -g vercel

# Deploy to Vercel
vercel --prod
```
